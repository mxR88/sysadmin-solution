Описание задачи
Необходимо автоматизировать развертывание локального веб-окружения с базовой защитой. Результат работы должен быть оформлен в виде Ansible-роли (или репозитория с Docker Compose), которую проверяющий сможет запустить одной командой.

Технические требования

1. Инфраструктура и ОС
Использовать любой современный серверный дистрибутив (рекомендуется Ubuntu Server 24.04 LTS / Rock Linux 9).
Развертывание должно происходить в контейнерах (Docker/Podman) ИЛИ хостовая ОС должна настраиваться через Ansible.



3. Безопасность и Доступ

SSH-сервер: Оставить стандартный порт (или сменить), но обязательно отключить PasswordAuthentication в sshd_config. 
Разрешить вход только по SSH-ключам. 
Запретить вход под пользователем root.

Файрвол: Использовать nftables или ufw для реализации концепции Zero Trust (запрещено всё, что не разрешено явно).

Пользователи: Создать двух пользователей:
admin-user: доступ строго по SSH-ключу,
deploy-user: доступ строго по SSH-ключу.





Формат сдачи задания
Репозиторий должен содержать:
Код автоматизации (Ansible playbook / Docker Compose + скрипты).
Файл README.md с краткой инструкцией, как проверяющему запустить проект одной-двумя командами.
